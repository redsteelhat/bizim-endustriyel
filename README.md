# Bizim Endüstriyel

Bizim Endüstriyel için hazırlanmış, satış ve kurumsal teklif dönüşümüne odaklanan modern hırdavat ve nalbur e-ticaret vitrini.

## Özellikler

- Ürün arama, kategori filtreleme ve fiyat sıralama
- Hızlı ürün inceleme ve favoriler
- Tarayıcıda saklanan sepet ve adet yönetimi
- WhatsApp için hazırlanan sipariş ve kurumsal teklif akışları
- Masaüstü, tablet ve mobil uyumlu arayüz
- Türkçe SEO ve sosyal paylaşım metadataları
- Erişilebilir klavye ve hareket azaltma desteği

## Teknolojiler

- React 19
- TypeScript
- Vinext / Vite
- Cloudflare Workers uyumlu çıktı
- Özel responsive CSS tasarım sistemi

## Yerel Geliştirme

Node.js `22.13.0` veya daha yeni bir sürüm gereklidir.

```bash
npm install
npm run dev
```

Üretim sürümünü doğrulamak için:

```bash
npm run build
npm test
```

## Vercel Dağıtımı

Repo Vercel'e bağlandıktan sonra standart kurulum akışı kullanılabilir. Proje Vinext tabanlı olduğu için Vercel dağıtımından önce yapılandırmanın hedef çalışma ortamıyla uyumluluğu doğrulanmalıdır.

## İçerik Notu

Mevcut ürün, fiyat, stok ve kampanya bilgileri temsili katalog içeriğidir. Canlı satış öncesinde gerçek ürün verileri ve firma WhatsApp numarasıyla güncellenmelidir.
